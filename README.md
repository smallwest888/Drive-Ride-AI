# Drive-Ride-AI

Drive-Ride-AI is an AI-assisted commute planning project with iOS and web tracks.

## Repository layout

- `ios/` iOS application assets and documentation
- `web/` current web implementation, including frontend, API, shared models, and OpenClaw integration

## Web stack highlights

- English default UI with bilingual English / Chinese support
- Typed and voice-based trip requests
- Qwen ASR / TTS integration
- 3D globe route visualization
- OpenClaw / Clawdbot-backed planning flow
- Parking admin dashboard

See `web/README.md` for setup and runtime details.
